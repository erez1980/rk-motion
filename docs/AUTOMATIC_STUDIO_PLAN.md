# RK Motion — תוכנית מלאה לסטודיו אוטומטי

## ההוראה העדכנית של הבעלים

כל 10 שדרוגי המוצר וכל 20 רעיונות ה־AI נכללים בתוכנית. חוויית המוצר חייבת להיות **לחיצה אחת עם החלטות אוטומטיות**, ללא הקלדת prompt, בחירת שיר, בחירת פנים, סימון מקטעים, כוונון ספים או הגדרות ייצוא כתנאי להפקת סרט. בחירת מקור/אישור הרשאת מערכת בפעם הראשונה הם קלט הכרחי, לא עבודת עריכה. מסכים מקצועיים קיימים יכולים להישאר אופציונליים.

כל הניתוח, האינדקסים, העדפות המשתמש והרינדור נשארים באייפון. אין fallback שקט לענן, ל־Private Cloud Compute או למק. יש לשמור גם קוד וגם תוכנית ב־repository כדי ש־Claude Code יוכל להמשיך.

**תוכנית זו מחליפה ניסוחים ידניים במחקר המקורי.** למשל: בחירת גיבור תהפוך לבחירה אוטומטית לפי הופעה ובולטות; חיפוש יהפוך גם להצפה אוטומטית של זיכרונות קשורים; בימוי בשפה טבעית ייחשף דרך מתכונים בלחיצה. הורדת מודל או הרשאת מערכת אינן הוכחה שמודל מסוים קיים ופועל.

## סדר ביצוע מחייב להמשך

1. לסיים ולבדוק את המסלול הקיים באייפון פיזי ובמצב טיסה; לטפל בכל כשל לפני הוספת מודלים.
2. AI01+AI02+AI03: להביא 30–50 ימי צילום ברשות הבעלים, לתייג ולהפריד סט פיתוח/הערכה; למדוד את הבסיס הקיים לפני אימון.
3. AI07+AI08+AI13+AI20: שיפור בחירה/מסגור/למידה מדוד. cache, תקציב זיכרון וחום וחזרה מ־OS interruption.
4. G08+AI04+AI05: הרחבת מקורות פעילות אחרי הכרעת הרשאות/חתימה; מקור לכל נתון.
5. AI09+AI10+AI19: בחירת מודלים/נכסי שפה ושמע מקומיים, רישוי, גודל ו־benchmarks. עברית ב־Apple Intelligence אינה מובטחת; אין ענן שקט.
6. AI11+AI12: בדיקות אמינות והרחבת רב־מצלמה/מקום, לפני שימוש בנתונים האלה לסיפור עובדתי.
7. AI15+AI17: ניסויי מחקר נפרדים, מדדי עצירה ברורים ו־feature availability אמיתי. להימנע מהבטחות טיפוליות/תלת־ממד/זמן אמת בלי ראיות.
8. להשלים G03/G04/G06/G10, גיבוי/מחיקה ומכשירים חלשים בכל השלבים.

## Definition of done לכל יכולת

- לחיצה מפעילה פעולה מלאה או הסבר אמיתי על קלט/יכולת מערכת חסרים; ללא wizard או prompt חובה.
- אותו renderer ותוכנית זמן משותפים לתצוגה ולייצוא; עובדות מקור נפרדות מהשערת מודל.
- פעולה בבעלות Task שניתן לבטל, פרסום אטומי אחרי validation, שמירת מקור, cleanup לקבצי ביניים ושחזור לאחר restart.
- בדיקות meaningful ל־failure, cancellation וגבולות קובץ; תיעוד מכשיר/OS/מודל/מדידה.
- מעבר מצב טיסה אחרי התקנת הנכסים. אין API בענן, telemetry חיצוני או חשבון חובה.
- בטבלת המצב כתוב בנפרד: implemented / partial / research, ומה בדיוק אומת. אין לסגור את כל 30 השורות רק מפני שקיימת תשתית.

## אבני דרך להדגמה

1. סרט אוטומטי מהגלריה או מפרויקט, כולל פסקול, בחירה ובדיקה, בלי שלבי עריכה.
2. אירוע אמיתי שנשמר בשלמותו ואינו נחתך לפני התוצאה; הדגמה עיוורת מול 0.32.
3. עריכה אישית שמשתפרת מבחירות מתכון/התנהגות מפורשת, תוך שמירת כל הנתונים במכשיר.
4. אותה פעולה משתי מצלמות עם סנכרון שנמדד; אחר כך 3+ מצלמות וקבצים ארוכים.

היעד הוא כל 30 היכולות. המימוש המצורף הוא בסיס עובד ולא השלמה של כל המחקר.
